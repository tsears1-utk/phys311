Lab 9 — Multi-Body Browser Simulation. This project completes the Lab 8 browser engine port by organizing the physics into engine modules (Vec2, Body, forces, integrators, collisions, and World) and keeping canvas drawing in separate render modules (camera, renderer, and HUD). It includes three selectable scenes, a 24-ball billiards/ball-pit with wall and circle collisions plus a static obstacle and adjustable restitution; a five-body softened Newtonian gravity system using Velocity Verlet; and a damped spring-mass array using gravity, quadratic drag, and spring forces. The canvas HUD reports simulation time, body count, total mechanical energy, fractional energy drift, momentum magnitude, FPS, physics time, and render time, with energy drift percentage. The controls allow scene selection, runtime integrator switching, timestep selection, restitution adjustment, pause/reset, a separating-guard jitter demonstration, a 20-body 60-second momentum/energy validation, a 60-second N-body stability test, and a 20/50/100/200-body performance benchmark. Open index.html with the VS Code Live Server extension. Keep the browser Console visible for the test output.
