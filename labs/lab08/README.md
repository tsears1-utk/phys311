Lab 8 — JavaScript Physics Engine Port

This project ports the Lab 7 two-dimensional body state and integration pattern to JavaScript and HTML5 Canvas. It includes the required Vec2 operations, a labeled coordinate-transform demo, a 20 m/s projectile launched at 50 degrees, Euler–Cromer and Velocity Verlet integrators, a fading trajectory trail, and a live HUD for time, position, speed, kinetic energy, gravitational potential energy, and total energy. The controls allow the user to display the static coordinate demo, run the Vec2 self-test, switch integrators, change DT, pause or reset, compare a fixed-step accumulator with a variable-frame-time mode, inject a short lag, and run a headless 10-second validation. Open index.html with the VS Code Live Server extension (do not open it through file://), leave the browser Console visible for the Vec2 and headless tests, and use validation/python_reference.py to generate the corresponding Lab 7 Python reference values. The timestep and integrator controls reset the animation so comparisons can begin from identical initial conditions.
